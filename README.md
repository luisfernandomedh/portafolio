# portafolio

Tarjeta de contacto de una sola pantalla: WhatsApp, LinkedIn y
[Constata](https://www.constata.dev). Pensada para compartirse con una
etiqueta NFC o un QR.

- `index.html` — la página (sin dependencias externas salvo Google Fonts)
- `liquid-glass.js` — refracción de cristal, de
  [deepika-builds/liquid-glass](https://github.com/deepika-builds/liquid-glass).
  Solo Chromium; Safari y Firefox reciben el esmerilado de respaldo.
- `luis-medina.vcf` — ficha de contacto descargable

No indexado a propósito (`robots.txt` + `<meta name="robots" content="noindex">`).
Se comparte por enlace, no por buscador.
